# automation-e-commerce
Playwright automation to test e-commerce website

Step 1
Install playwright with python pytest

Step 2
Just execute the testcase file from terminal using command : 
pytest test_file.py

Note : <br>
-- headed :  to make visible automation (by default playwright uses headless) <br>
-s : to make print command result appear <br>

sample : <br>
pytest test_file.py --headed -s
